# Dashboard Control Implementation Plan

## 1. 后端行为与测试

- 为暂停、恢复并补充、停止 Agent、设备急停编写 API 和平台测试。
- 为节点运行追踪、日志、健康快照、模型配置和用量统计编写测试。
- 先运行目标测试，确认因接口缺失而失败。

## 2. 平台实现

- 扩展任务控制状态与调度规则。
- 在每个 LangGraph 节点外记录运行跨度和结构化日志。
- 增加急停命令、组件心跳、模型配置和用量聚合。
- 暴露对应 FastAPI 路由并保持 API Token 保护。

## 3. Dashboard 实现

- 将单页界面扩展为多视图实验控制台。
- 增加节点监控、人工干预、停止按钮、健康状态、日志、模型与调试控件。
- 保留三类任务表单、结果曲线和实验记忆。

## 4. 教程与验证

- 扩写小白教程，逐层解释 FastAPI、LangGraph、Gateway、Arduino JSON 串口和影刀 Bridge。
- 解释关键代码、停止边界、日志路径、配置方法和真实设备接入步骤。
- 运行 pytest、Ruff、构建和浏览器交互验证，然后提交并推送 GitHub。
