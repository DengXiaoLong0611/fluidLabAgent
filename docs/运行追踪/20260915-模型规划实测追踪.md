# 模型规划实测追踪

> 运行模式：`simulation`。本次没有启动 Bridge、Arduino、DaVis 或影刀 RPA；没有创建任何设备操作单。API Key 已从本文件、日志和命令中移除。

## 1. 本次实际流程

```text
创建 PIV 任务（status=queued）
  -> FastAPI/Platform 后台调度器调用 Platform.tick()
  -> LangGraph 进入 plan 节点
  -> Platform.plan() 固定选择工具 davis.capture
  -> model_advisor.consult() 调用当前选中的模型
  -> 将 advice、Token、延迟写入 SQLite
  -> 任务变为 planned

下一次 tick 才会继续：planned -> dispatch -> waiting -> evaluate
```

## 4. 代码位置与职责

| 代码位置 | 作用 |
| --- | --- |
| `src/labagent/api.py` | FastAPI 启动后台调度器；每 0.5 秒调用一次 `Platform.tick()`。 |
| `src/labagent/platform.py` | 当前真实的 LangGraph 工作流：`inspect -> plan -> dispatch -> evaluate`。同时负责数据库、日志、暂停和操作单。 |
| `src/labagent/model_advisor.py` | 根据设置调用 Ollama 或 DeepSeek，并返回建议、Token、费用和延迟。这里没有硬件工具。 |
| `src/labagent/bridge.py` | 将来独立运行的设备/RPA 执行进程；当前测试没有调用它。 |
| `src/labagent/device_gateway.py` | 设备网关抽象；用于将来接入 Arduino、驱动器或 PLC。 |
| `src/labagent/static/app.js` | 浏览器工作台；调用 `/api/tasks`、`/api/logs` 等 API 并展示状态。 |
| `src/labagent/graph.py` | 较小的 LangGraph 学习示例；工作台主流程实际使用 `platform.py`。 |
| `src/labagent/specialist.py` | 旧的 OpenAI/LangChain 示例，当前工作台主流程没有调用它。 |

## 5. 有没有循环？是不是 ReAct？

有两类循环，但当前不是 ReAct Agent：

1. **调度循环**：`api.py` 的后台协程每 0.5 秒调用一次 `Platform.tick()`。它扫描数据库中的活动任务，让每个任务前进一个可记录、可恢复的节点。
2. **实验循环（未来）**：任务可以走 `plan -> dispatch -> evaluate`；真正的“测量结果不好就调整翼板/风扇再测一次”反馈循环尚未实现。

当前没有 ReAct 的 `Thought -> Tool -> Observation -> Thought` 循环：

- `Platform.plan()` 先用固定模板选择 `davis.capture`、`flap.set` 或 `flow.set`。
- `model_advisor.consult()` 只请求模型一次来获取建议。
- 模型没有注册工具，不能自己连续调用电机、PIV 或 RPA。

因此，当前是“**LangGraph 状态机 + 可选 LLM 顾问**”，不是“自主 ReAct 工具调用 Agent”。未来加入 Arduino Tools 后，仍应保留安全路径：`Agent 建议 -> 参数校验 -> 人工批准 -> Gateway -> Arduino`。
