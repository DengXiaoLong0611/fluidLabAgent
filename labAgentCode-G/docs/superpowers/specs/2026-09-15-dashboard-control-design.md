# Fluid Lab Agent 运行控制台设计

## 目标

在现有三类实验任务之上增加一套可观察、可干预、可安全停止的浏览器工作台。工作台服务科研人员，不承担任意 shell 远程执行，也不把模拟结果冒充真实硬件结果。

## 控制语义

- **暂停流程**：当前 LangGraph 节点执行结束后，不再进入下一个节点；不会切断正在运动的硬件。
- **继续流程**：恢复图调度，可附带一条人工补充说明，记录进任务事件与干预历史。
- **停止 Agent**：阻止后续 LangGraph 节点和 LLM 调用；若设备已经运动，仍需另外执行设备急停。
- **设备急停**：创建最高优先级的设备停止命令，并等待 Gateway/设备确认。网页返回“已请求”不代表机械已经制动。

真实设备必须另有实体急停按钮、限位开关和独立看门狗。软件急停只是其中一层。

## 可观察数据

每次节点执行记录节点名、状态、开始时间、结束时间、耗时、输入摘要、输出摘要和错误。Dashboard 同时显示任务状态、组件健康、最近日志、模型设置、Token 用量和估算费用。

## 系统边界

- FastAPI 提供浏览器和 Bridge 共用的 HTTP API。
- LangGraph 只负责流程决策与状态推进，不直接驱动引脚。
- Device Gateway/Bridge 负责把受约束的操作转换成 Arduino 串口 JSON 指令。
- Desktop Bridge 负责对接实验室自建的影刀 HTTP 流程；实际影刀开放能力需按现场版本确认。
- API Key 只从服务器环境变量读取；网页仅选择已配置的 provider/model 别名。
- 运行控制台仅提供白名单诊断，不提供任意 Bash 输入框。

## 页面结构

1. 总览：组件健康、活动任务、Token 与费用摘要。
2. 流程监控：LangGraph 节点时间线、输入输出、暂停/继续/停止。
3. 任务：保留三类实验创建、任务状态和结果曲线。
4. 设备与急停：Gateway、Arduino、RPA 状态以及分设备/全部急停。
5. Agent 与日志：模型切换、温度/Token 限制、日志与安全诊断。
6. 实验记忆：保留已完成实验经验并支持删除。
